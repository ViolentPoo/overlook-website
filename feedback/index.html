Before posting

Submitting feedback requires a free GitHub account. Please search existing issues first so related reports can stay together.

View existing reports & requests ↗

What happens next?

Reports and requests are public discussions. They may be reviewed, clarified, labeled, or closed as development progresses. A submitted request is not a promise of implementation or a release date.

Keep sensitive details private.
Do not post passwords, access tokens, private server addresses, personal account information, sensitive logs, or other confidential information. Screenshots and diagnostics are optional and should be reviewed before posting.

Before you post

Public issues are not private support.

OVERLOOK does not currently offer a private support channel. Share only information that is safe to make public.
