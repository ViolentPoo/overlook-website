Contact

The official project identity.

This page identifies OVERLOOK and provides a stable public point of contact for users, service operators, and API administrators.

Public inquiries

General questions, bug reports, and feature ideas can be submitted through the public GitHub issue tracker. A free GitHub account is required, and everything posted there is publicly visible.

Open feedback portalView public issues ↗

Private or operational inquiries

A private support channel is not currently offered. Do not place confidential information in a public issue. Public reports should contain only details that are safe to share openly.

Wikimedia API identification

Wikimedia requires API clients to send an identifying User-Agent with contact information. This website provides that stable public contact point.

OVERLOOK uses its installed application version in the identifying format:

OVERLOOK/version (https://violentpoo.github.io/overlook-website/) AndroidTV

This website does not constitute OAuth registration, confer special API privileges, or establish commercial data licensing. See the official Wikimedia API access policy ↗.
